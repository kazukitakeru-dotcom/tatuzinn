# 達人への道（スマホ版）

分野ごとの積み上げ時間を記録して、10,000時間 = Lv.100 を目指すアプリのスマホ版。
PC版（Electron / `達人への道` フォルダ）と同じデータ形式を使い、Supabase 経由で
**どちらの端末からでも両方の記録が見えて、両方の内訳を Obsidian に書き出せる。**

## 使い方

1. ブラウザで開く → 共有 →「ホーム画面に追加」でアプリとして使える（オフラインOK）
2. 分野を選んで **START** / **STOP** で記録
3. 記録には「どの端末で記録したか」が付く（設定タブの端末名）

## PCと同期する

わんにゃんメモリーと**同じ Supabase プロジェクトに相乗り**している。

1. 初回だけ、`supabase.sql` を Supabase ダッシュボードの SQL Editor で実行してテーブルを作る
2. PC版とスマホ版の設定タブで、**同じアカウントにログイン**する（わんにゃんメモリーと同じアカウントでよい）

これで、

- PCで記録中なら、スマホの「記録中」欄に `PC が 絵 を 1:23:45 記録中` と出る
- どちらの端末からでも、両方の合計・内訳を Obsidian に書き出せる

オフライン中の記録は「未送信」として端末に溜まり、次につながったときに送られる。

### 同期の作り

| テーブル | 役割 | 衝突しない理由 |
| --- | --- | --- |
| `tatsujin_sessions` | 記録1件＝1行 | 追加しか起きない |
| `tatsujin_live` | 端末ごとの「いま記録中」 | 端末につき1行 |
| `tatsujin_state` | 分野の構造・改名・削除 | 小さいので `core.js` のマージで解決 |

分野を改名しても、保存済みの行は旧名のまま残る。`renames` の履歴をたどって現在の名前に
読み替えるので、オフライン中に改名しても記録は迷子にならない。

`created: 0` は「アプリが勝手に作った初期分野」の印。これがないと、片方で消した初期分野が
もう片方の初期分野として復活してしまう。

## Obsidian への書き出し

「書出」タブから。出力されるノート:

| ファイル | 中身 |
| --- | --- |
| `達人への道.md` | 全分野のサマリー。分野 × 端末の表、端末別の合計 |
| `分野/<分野名>.md` | その分野の概要・端末別・月別・全セッション履歴 |

- スマホ: **ZIP**（フォルダ構造ごと）か **1ファイル .md**。共有シートから「ファイルに保存」→ vault を選ぶ
- PC版: vault に**直接書き込み**（`<vault>/達人への道/` 以下）

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `core.js` | レベル計算・データ構造・移行・端末間マージ ※PC版と同一 |
| `supa.js` | Supabase のログインと読み書き ※PC版と同一 |
| `obsidian.js` | Markdown 生成・ZIP 作成 ※PC版と同一 |
| `app.js` | スマホ版の画面 |
| `supabase.sql` | テーブル定義（ダッシュボードで実行する） |

`core.js` / `supa.js` / `obsidian.js` は PC版（`達人への道/`）と**同じ内容を保つこと**。
片方を直したらもう片方にコピーする。`sw.js` の `CACHE_NAME` のバンプも忘れずに。
